# Temporary photograph and decoration asset audit

The goal is visual comparison with Save Walter White, not publication of television stills under a new identity.

- **Source**: `https://github.com/matiasroj0/save-walter-white/tree/508d0aea07fb3dee18f8dda23ee93e6b5e3a2a3f/images` (community remake).
- **Primary image host**: `raw.githubusercontent.com`, pinned to exact source revision `508d0aea07fb3dee18f8dda23ee93e6b5e3a2a3f`.
- **Secondary image host**: `cdn.jsdelivr.net/gh/matiasroj0/save-walter-white@508d0aea07fb3dee18f8dda23ee93e6b5e3a2a3f`, same source and same photographs.
- **Slots**: `walter_1.jpg` to `walter_7.jpg` in reference order. The repeating star tile and two bows also use the pinned revision.
- **Image policy**: hero loads eagerly/high priority, six supporting photos load lazily. HTML provides width/height hints; CSS preserves intrinsic ratios (no object-fit crop). A tiny Astro-served script changes image URLs only when loading fails. Both sources failing produces a visible placeholder instead of a misleading photograph.
- **Rights**: use rights are **not verified**. This repo deliberately does not contain redistributed JPG/PNG frames. A publicly readable file is not a license to publish or commercialize it.
- **Release gate**: replace the seven stills and decor with owned/licensed images if you want to launch publicly or commercially; confirm each image's source/license and update alt text and visual review. Do not turn the vintage CTA into real payment collection without a separate explicit request and policy review.

This code does not fetch copyrighted images during build or persist them in output artifacts; screenshot artifacts are generated by browser tests as temporary review evidence.
