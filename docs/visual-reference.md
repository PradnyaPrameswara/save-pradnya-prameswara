# Visual reference and current fidelity
The target aesthetic is the fictional 2009 **Save Walter White** single-page site. The reference layout was cross-checked against the public [matiasroj0 reproduction](https://github.com/matiasroj0/save-walter-white), its CSS, and archived screenshots. This reproduction is a reference, not an authoritative pixel-perfect copy of the original live site.

## Anchors
- Green (#1ba11a) repeating sparkle tile, aligned from the upper-left.
- Centered column with a maximum width of 700px.
- Large white Times-style title and yellow comic-style body/subtitle, white supporting story.
- Same order of seven temporary Walter White photographs, displayed without intentional crops.
- Three-photo row, family photo, two-photo row, ribbon appeal, tan banner, red beveled help button, black counter and compact footer.
- Original reference content is **not** copied: this is an independent parody about developer life and does **not** collect donations.

## Known deviations and limits
- The Pradnya name and parody copy differ in length, so matching element positions pixel-for-pixel across the *whole page* is not possible without changing the content.
- The title/banner and support interaction are recreated in CSS; the original raster heading/donate graphics are not reused.
- Comic Sans is preferred where locally installed; Comic Neue from Google Fonts is an optional freely available fallback. If external fonts are unavailable, the browser uses its own cursive fallback.
- Photo and decorative assets are remote temporary references. Their reuse rights are unverified; do not publish as a real fundraising campaign.
- Visual parity tests check grounded layout constraints, not a fabricated numeric similarity score.
